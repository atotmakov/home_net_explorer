# Data Model: LAN Inventory & Topology Explorer

**Feature**: `001-lan-inventory-topology` | **Date**: 2026-10-04

Storage is a single SQLite database (see [research.md](research.md) R5). Tables are in two groups:

- **Facts**: append-only, the source of truth. These are `collection_runs` and the `user_*`
  tables.
- **Projections**: derived, and can be rebuilt from the facts by `hne-server rebuild`. These are
  `sightings`, `devices`, `device_addresses`, `events`, and `links`.

All timestamps are UTC, stored as RFC 3339 text with milliseconds. IDs are integers unless noted.

## Facts

### Collector

A source of observations. The server's built-in scanner is the collector named `nas`, which
`hne-server init` creates automatically.

| Field | Type | Rules |
|-------|------|-------|
| id | int | PK |
| name | text | unique, 1–64 chars, `[a-z0-9-]` |
| kind | enum | `builtin` \| `remote` |
| token_hash | blob | SHA-256 of the token. Null for `builtin` |
| created_at | ts | |
| revoked_at | ts? | When set, uploads get 401 |
| interval_seconds | int | Reported by the collector on each run. Default 900 |
| last_report_at | ts? | Projection convenience, updated on ingest |
| last_clock_skew_ms | int? | `sent_at` minus server receive time |

### Subnet

| Field | Type | Rules |
|-------|------|-------|
| id | int | PK |
| cidr | text | unique. A **private (RFC 1918)** IPv4 CIDR with a prefix from /16 to /30 |
| name | text | optional label, e.g. "Home LAN" |
| ignored | bool | default false. When true, the subnet is hidden, collectors skip it, and its observations are dropped at ingest |
| first_seen_at | ts | when a run first reported it |
| discovered_by | int | FK → Collector |

There is **no initial subnet list**. A subnet row is created when a run first reports it
(research R14). The owner's ignore and rename actions are user facts (below), so a rebuild
reproduces them.

### CollectionRun (source of truth)

One completed scan by one collector. It is immutable once stored.

| Field | Type | Rules |
|-------|------|-------|
| collection_id | uuid text | PK. Generated by the collector. A duplicate upload is a no-op |
| collector_id | int | FK → Collector |
| schema_version | int | Must be supported (currently 1) |
| started_at / finished_at | ts | finished_at ≥ started_at |
| sent_at | ts | Used for clock skew |
| received_at | ts | Server time |
| payload_gz | blob | The original request body, gzip-compressed |

The run's per-subnet scan results (which subnets were scanned, by what method, and whether they
completed) are kept in the payload and also in a small child table:

**RunSubnet**: (`collection_id`, `cidr`, `method` = `arp` \| `icmp_tcp` \| `skipped`,
`skip_reason` = `too_large` \| `ignored` \| null, `complete` bool, `hosts_probed` int). This is
what offline detection counts (R7). Skipped entries never count as completed scans.

### Observation (inside a run payload)

A single sighting. It is not stored as its own row; it is folded into `sightings`.

| Field | Rules |
|-------|-------|
| observed_at | within [started_at, finished_at] of the run |
| ip | IPv4, must fall inside one of the run's scanned subnets |
| mac | optional, lower-case `aa:bb:cc:dd:ee:ff`. Required when method = `arp` |
| hostname | optional, ≤ 253 chars |
| hostname_source | `dns` \| `mdns` \| null |
| method | `arp` \| `neighbor_cache` \| `icmp` \| `tcp` |

### Vantage report (inside a run payload)

This is the collector's own interfaces and routes (R4). It is stored in the payload and projected
into `links`.

### User facts (append-only; each row is an edit)

| Table | Fields | Purpose |
|-------|--------|---------|
| user_device_attrs | identity_key, field (`name`/`notes`/`type`), value, at | Friendly name, notes, type (FR-014). The latest row wins |
| user_identity_alias | identity_key, target_identity_key, at, kind (`merge`/`split`) | Manual merge and split (FR-015) |
| user_links | from_identity_key, to_identity_key, at, removed bool | Manual "connected via" (FR-026) |
| user_acks | identity_key, at | Acknowledging a "new" device (FR-023) |
| user_subnet_attrs | cidr, field (`name`/`ignored`), value, at | Rename or ignore a subnet (FR-006) |

User facts reference the device's stable **`identity_key`**, never the numeric `devices.id`. Facts
for a merged device are resolved through its aliases, and the latest edit wins across all its keys.
`devices.id` is internal to the derived tables and is used only in UI URLs.

Device type values: `router`, `access_point`, `switch`, `computer`, `phone`, `tablet`, `tv`,
`printer`, `nas`, `iot`, `other`.

### Settings

`settings(key, value)`: owner password hash, scan interval for the built-in collector (default
900 s), offline threshold multiplier (default 3). There is no retention setting: history is kept
indefinitely (FR-024).

### Sessions

`sessions(id_hash, created_at, expires_at)`: owner login sessions (R10).

## Projections

### Sighting

A run-length compressed history of observations. One row covers a distinct tuple across
consecutive runs.

| Field | Type | Rules |
|-------|------|-------|
| id | int | PK |
| device_id | int | FK → Device |
| collector_id | int | FK |
| subnet_id | int | FK |
| ip | text | |
| mac | text? | |
| hostname | text? | |
| first_seen / last_seen | ts | |
| seen_count | int | ≥ 1 |

When a new observation matches the device's latest sighting for the same collector and subnet
(same IP, MAC, and hostname), that sighting's `last_seen` is extended. Otherwise a new sighting row
is created, and a change event fires.

### Device

| Field | Type | Rules |
|-------|------|-------|
| id | int | PK. Assigned in **ingest order**. A rebuild reproduces it exactly, because replay follows ingest order |
| identity_key | text | unique. `mac:<mac>`, `host:<subnet>:<hostname>`, or `ip:<subnet>:<ip>` |
| identity_strength | enum | `strong` (MAC) \| `weak` |
| mac_randomized | bool | locally-administered bit set |
| manufacturer | text? | OUI lookup (R11). Null for randomized or unknown MACs |
| status | enum | see state machine |
| first_seen / last_seen | ts | |
| display_name | text | user name, else hostname, else IP |

**DeviceAddress**: (`device_id`, `subnet_id`, `ip`, `current` bool). A device can have several
current addresses on different subnets (multi-homed edge case).

### Device status state machine

```text
                 first observation
                        │
                        ▼
                 ┌─────────────┐   user acknowledges   ┌──────────┐
                 │  new        │ ────────────────────▶ │  online  │
                 └─────────────┘                       └──────────┘
                    │      ▲                              │    ▲
     offline rule   │      │ seen again (unacked)         │    │ seen again
                    ▼      │                offline rule  ▼    │
                 ┌───────────────┐                     ┌──────────┐
                 │ new_offline   │                     │ offline  │
                 └───────────────┘                     └──────────┘
```

- **Baseline**: devices first seen in the **first completed scan of a subnet** (by any collector)
  start as `online`, not `new`. A `new_device` event is still recorded for history.
- The offline rule is defined in research.md R7. It is evaluated only at ingest, using scan
  timestamps.
- If every collector covering a device's subnet is silent, the device keeps its status, and the
  subnet is marked **stale**. Devices are not marked offline in this case.
- `merged_away`: a terminal status for a device record absorbed into another by a merge. It is
  hidden from lists and kept for history.

### Event

| Field | Type | Rules |
|-------|------|-------|
| id | int | PK |
| at | ts | **observation time**, not arrival time (late-upload edge case) |
| device_id | int | FK |
| type | enum | `new_device`, `ip_changed`, `hostname_changed`, `mac_changed`, `went_offline`, `came_online`, `merged`, `split` |
| subnet_id | int? | |
| old_value / new_value | text? | e.g. old and new IP |
| collector_id | int? | |

Events are unique on (device_id, type, at, new_value), which keeps re-ingesting or rebuilding from
creating duplicates (FR-011).

### Monotonic device state (late uploads)

A device's current addresses and hostname only change based on observations **newer** than the
current value's timestamp for that subnet. An older observation (e.g., from a collector's spool
after an outage):

- only extends or inserts a sighting record,
- doesn't emit `ip_changed` or `hostname_changed`, and
- doesn't roll back the device's current state.

`new_device` still fires at the observation's time if the device was unknown.

### Link

| Field | Type | Rules |
|-------|------|-------|
| id | int | PK |
| kind | enum | `gateway` (device ↔ subnet), `bridge` (device in 2+ subnets), `manual` (device → device) |
| from_device_id | int | |
| to_device_id | int? | for `manual` |
| subnet_id | int? | for `gateway` / `bridge` |
| source | enum | `inferred` \| `user` |

User links override inferred links that point at the same device.

## Relationships

```text
Collector 1─* CollectionRun 1─* RunSubnet *─1 Subnet
CollectionRun ──(fold)──▶ Sighting *─1 Device 1─* DeviceAddress *─1 Subnet
Device 1─* Event
Device 1─* Link
User facts ──(apply)──▶ Device / Link
```

## Validation summary (enforced at ingest; failures → 400/422 per contract)

- Every subnet `cidr` must be private (RFC 1918) with a prefix from /16 to /30.
- `ip` must be inside a scanned subnet of the same run.
- `mac` format must be valid. MAC is required when method is `arp`.
- `observed_at` must be within the run window. The run window must be no longer than 1 hour and must
  not be more than 5 minutes in the future relative to `sent_at`.
- No more than 4096 observations and 16 subnets per run.
- `schema_version` must be supported.

## Rebuild invariant (tested)

Delete all projections. Replay one merged stream: `collection_runs` ordered by `received_at`, and
user facts ordered by `at`. When timestamps tie, the scan goes first. The result MUST equal the
incrementally built projections (Principle V). This works because live processing happens in
exactly that order on the server's clock. Nothing in the projections depends on the current time
(stale status is computed when a page loads, research R7).
